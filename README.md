# 테이트 미술관 터너전 「숭고의 회화, 현대미술과의 대화」 한국어 작품 목록 · 도슨트

국립서양미술관 **「テート美術館 ターナー展 ―― 崇高の絵画、現代美術との対話」**
(Turner: Painting the Sublime, in Dialogue with Contemporary Art · 国立西洋美術館 · 2026.10.24 – 2027.2.21)
출품작의 비공식 한국어 브로셔 웹페이지입니다. 전시장에서 휴대폰으로 보는 것을 기준으로 만들었습니다.

- 출품작 106점 + 참고 자료 8점(R-), 9개 구역: 프렐류드 · 1–7장 · 색채 실험실
- 작품별 도슨트 해설과 "이렇게 보세요" 감상 포인트, 일부 작품은 비교 작품 이미지
- 장별 「Viewpoint」 해설 (전시장 배포 자료 요약·번역) + 전시 개념 「숭고」 소개
- 오디오 도슨트: 브라우저 음성 합성, 읽는 문단 강조, 속도 조절
- 전시장 안내도: 평면도의 방을 누르면 해당 장으로 이동, 장별 사진 촬영 가능 여부 표시
- 검색(작가·작품명·번호, `R1`처럼 참고 자료 번호도 가능), ★ 주요작 필터, 실제 크기 비교 그림
- 테이트 소장품은 소장 번호와 테이트 소장품 페이지 링크

제작 · 문의: [아트프렌즈 아트버스](https://artfrnd.com/) · info@artfrnd.com

## 실행

```bash
npm install
npm run dev        # 개발 서버 → http://localhost:3000
```

배포용 정적 파일 만들기:

```bash
NEXT_PUBLIC_SITE_URL=https://배포도메인 npm run build   # → out/ 폴더
```

- `out/` 폴더를 그대로 정적 호스팅(Netlify, Vercel, S3, GitHub Pages 등)에 올리면 됩니다.
- `NEXT_PUBLIC_SITE_URL`은 카카오톡 등 링크 공유 미리보기 이미지(og:image)의 절대 주소에 쓰입니다.

> **주의**
> - 개발 서버를 켜 둔 채 `npm run build`를 하면 `.next` 캐시가 덮어써져 오류(500)가 납니다. 빌드 전에 개발 서버를 끄세요.
> - 빌드할 때 Google Fonts를 내려받습니다. 네트워크 상태에 따라 `next/font` 오류가 나면 다시 빌드하세요.

## 작품 이미지

`public/works/`에 **작품 번호로 시작하는 파일명**으로 넣으면 자동으로 연결됩니다.

```
072-n00546.jpg      ← 현재 형식: 3자리 도록 번호 + 테이트 소장 번호
72.jpg              ← 이렇게 넣어도 인식됨
```

- 번호는 **도록 번호(cat. no.)** 입니다. 같은 번호 파일이 여러 개면 파일명 순서상 첫 번째를 씁니다.
- `번호_…` (밑줄) 형식은 인식하지 않습니다. 번호 체계가 다른 파일이 섞여 들어가는 것을 막기 위해서입니다.
- 참고 자료(R-)에는 이미지를 쓰지 않습니다.
- 지원 형식: `jpg`, `jpeg`, `png`, `webp`, `avif`. 배포본은 **다시 빌드해야** 반영됩니다.

현재 상태 (91점):
- 테이트 소장 터너 작품: 테이트 공개 이미지(긴 변 1536px). 테이트에서 600px밖에 받을 수 없던 작품은 직접 받은 800px 이미지로 교체했습니다.
- 일본 소장 터너 작품(14·19 고리야마, 42 도치기, 74 도쿄 후지)과 110 로스코: 직접 받은 이미지
- 이미지 없음: 저작권 보호 기간의 현대 작가(7, 21–23, 31, 43, 57, 71, 80, 88, 89, 108), 구리하라 주지(59, 60, 90) — 상세 화면에 안내 문구가 나옵니다.

비교 작품(`public/compare/`)은 `app/notes.ts`의 `COMPARE`에서 작품 번호와 연결합니다.

## 내용 수정하기

### 작품 정보: `app/data.ts`
`groups`의 장별 배열에서 한 줄이 작품 1점입니다.

```ts
["번호", [작가 한국어, 작가 원어, 생몰년], "한국어 제목", "영어 제목", "일본어 제목",
 ["한국어 연도", "영어 연도"], [재료 한국어, 재료 영어], [소장 한국어, 소장 영어, 테이트 번호?],
 "세로×가로(cm)"?, { object?, sizeNote? }?],
```

- 크기는 테이트 공개 컬렉션 데이터(support 기준)를 cm로 옮겼습니다. 크기가 있으면 크기 비교 그림이 나옵니다.
- 테이트 소장품은 `TB("N00459")`(터너 유증) 또는 `TATE("purchased 1973", "P07082")`로 씁니다.
- 저작권 보호 작가는 `MODERN` 목록에 넣으면 이미지 없음 안내가 바뀝니다.

### 장 소개·Viewpoint: `app/data.ts`의 `chapters`, `sublime`
### 도슨트 해설: `app/docent-*.ts`
```ts
"72": {
  script: ["문단 1", "문단 2"],   // 본문
  look: ["감상 포인트 1"],         // "이렇게 보세요"
},
```
### 주요작(★)·비교 작품: `app/notes.ts`
### 관람 안내·푸터: `app/Catalogue.tsx`의 `<section id="info">`, `<footer>`
### 안내도: `app/FloorMap.tsx`의 `AREA`(방 클릭 영역, % 좌표, 방 하나에 사각형 여러 개 가능)

## 오디오 도슨트

브라우저 내장 음성 합성(Web Speech API)을 씁니다. 별도의 음성 파일은 없습니다.

- 문장 단위로 나눠 차례로 읽고, 읽는 문단을 강조합니다.
- 음성으로 읽을 때만 기호를 다듬습니다 (`WorkSheet.tsx`의 `forSpeech`): 〈〉·따옴표 제거, `No. 26`→"26번", `R-1`→"참고 자료 1", `cm`→센티미터, 괄호 속 외국어 생략 등.

## 자료 출처와 주의사항

- **작품 목록:** 전시장 배포 「作品リスト List of works」(`2026turner_JE_listofworks.pdf`). 빠진 번호(34·36·58·67, R-2)는 도쿄 전시에 나오지 않습니다.
- **Viewpoint·숭고 소개:** 전시장 배포 해설 자료(`2026turner_Viewpoint.pdf`)를 요약·번역했습니다.
- **크기·소장 번호:** 테이트 공개 컬렉션 데이터(github.com/tategallery/collection). 일부 작품은 테이트가 제목을 갱신해 원제와 다를 수 있습니다.
- **관람 정보:** 회기·장소·문의처는 포스터 기준, 개관 시간·휴관일은 국립서양미술관 통상 운영 기준입니다. 관람료는 넣지 않았습니다. 최신 정보는 [국립서양미술관](https://www.nmwa.go.jp)에서 확인하세요.
- **사진 촬영:** 전시장 안내도의 카메라 표시를 바탕으로 했습니다. 2장은 안내도에서 표시가 분명하지 않아 비워 두었습니다.
- **번역 표기:** 작품 제목의 한국어 표기는 번역자 임의 번역입니다.
- **도슨트 해설:** 미술사적으로 널리 알려진 사실 위주로 썼고, 일화성 내용은 "전해집니다"로 표시했습니다. 공개 전 검토를 권장합니다.
- **이미지:** 테이트 미술관 및 각 소장처의 공개 이미지입니다. 저작권은 각 권리자에게 있습니다.
- **성격:** 이 페이지는 전시 주최 측과 관계없는 **비공식** 안내서입니다.
